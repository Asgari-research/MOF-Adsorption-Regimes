- the original code/source author file lists **seven authors**, including Hosein Alimardani, and states that the order matches an associated manuscript.

This repository does not silently choose between those records. Final authorship/order and contribution statements remain author-owned decisions.

## Current license state

The current Git repository contains a top-level MIT `LICENSE` file with copyright attributed to `Asgari-research`. That file pre-dates the audited repository overlay; the overlay itself did not introduce a license.

The supplied scientific/project materials do not independently establish that MIT licensing was approved by every relevant rights holder or that the intended license scope includes software, retained data, CIFs, and publication artwork. Therefore, before public release or DOI deposition, the authors should explicitly do one of the following:

1. confirm the MIT license and its intended scope; or
2. replace/remove it and document the approved software/data/artwork licensing terms.

Do not infer a license for third-party or externally sourced materials merely from their presence in the repository.
